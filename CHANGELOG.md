# Changelog

All release descriptions below summarize the development history; they are not claims that every behavior has passed final in-game testing.

## [1.5.0] - Release candidate (unreleased)

### Planned validation and polish
- Consolidate the six-module release and audit inter-module dependencies.
- Review small-screen configuration and journal spacing.
- Verify XP-attribution, level timing, zone time, and adaptive layout edge cases.
- Prepare publication documentation, real screenshots, and tested distribution ZIP.

**Status:** Do not mark as a public stable release until the checks in `docs/RELEASE_CHECKLIST.md` pass.

## [1.4.0] - Development
- Added cross-login online level-time accounting.
- Improved XP-change baseline handling and level-up overflow reconciliation.
- Added `/fl timing` diagnostics.

## [1.3.0] - Development
- Added the Leveling Efficiency view and configurable 60/90/120-second activity windows.
- Simplified XP-strip modes to **Current XP** and **Current + Rested**.
- Added peak sampled five-minute XP/hour metric.

## [1.2.0] - Development
- Added estimated active XP/hour and activity-aware time-to-level projections.
- Added vertical XP-strip display selection.

## [1.1.0] - Development
- Made docked panels reflow when individual panels are hidden.
- Made the dock and XP strip resize with visible panels.

## [1.0.0] - Development
- Added visual XP Sources charts.
- Added selectable gold border color presets.
- Improved level-history comparisons.

## [0.9.0] - Development
- Added zone XP/hour rankings and better recent-rate sampling.
- Expanded history rate comparisons.

## [0.8.0] - Development
- Split the addon into Core, Tracking, Tracker, Journal, Config, and Commands modules.
- Switched to Blizzard-style gold textured borders.
- Added zone tracking.

## [0.7.0] - Development
- Corrected History/Session view overlap with separate content frames.
- Added source attribution estimates and improved level recording.

## [0.6.0] - Development
- Added an in-game Leveling Journal with Session, Lifetime, and History views.
- Added recent-kill projections.

## [0.5.2] - Development
- Fixed tracker drag-release snapping and movement lock behavior.

## [0.5.0–0.5.1] - Development
- Added separate panel movement and persistent positions; iterated on dragging fixes.

## [0.1.0–0.4.0] - Development
- Established the compact XP tracker, panels, configuration, tooltips, and early statistics.
